1. rp2040js — Uri Shaked (MIT)
-------------------------------------------------------------------------------

Upstream: https://github.com/wokwi/rp2040js

rp2040js is a TypeScript emulator for the Raspberry Pi RP2040. Parts of
RP2350Sharp are derived from it. The scope is as follows.

Ported (a 1:1 C# port of the corresponding rp2040js source file):

    src/RP2350Sharp/Gdb/GdbConnection.cs   <- src/gdb/gdb-connection.ts
    src/RP2350Sharp/Gdb/GdbServer.cs       <- src/gdb/gdb-server.ts
    src/RP2350Sharp/Gdb/GdbTcpServer.cs    <- src/gdb/gdb-tcp-server.ts
    src/RP2350Sharp/Gdb/GdbUtils.cs        <- src/gdb/gdb-utils.ts
    src/RP2350Sharp/Gdb/IGdbTarget.cs      <- src/gdb/gdb-target.ts

Derived (reimplemented in C#, reproducing behaviour of the rp2040js original,
including emulator-specific artifacts that are not described by the RP2040
technical reference manual):

    src/RP2350Sharp/Peripherals/Usb/UsbPeripheral.cs
        (equivalent to rp2040js src/peripherals/usb.ts, device mode subset)
    src/RP2350Sharp/Peripherals/Usb/UsbCdcHost.cs

Developed with reference to rp2040js (written independently against the RP2040
technical reference manual, using rp2040js as a reference and for
corroboration; not a port):

    src/RP2350Sharp/Peripherals/Pio/**

Original work, NOT derived from rp2040js: everything else. In particular the
emulator core (the Arm Cortex-M33 CPU, the Hazard3 RISC-V cores, the DCP and
RCP coprocessors, and TrustZone), the CYW43 wireless emulation, and the
Bluetooth Low Energy stack are original to this project. rp2040js emulates a
different CPU architecture and contains no CYW43 or BLE emulation.

2. RP2350 boot ROM — Raspberry Pi Ltd (BSD-3-Clause)
-------------------------------------------------------------------------------

Upstream: https://github.com/raspberrypi/pico-bootrom-rp2350

RP2350Sharp redistributes the real RP2350 boot ROM image, dumped from A2
silicon, so that the emulator can execute the actual on-chip ROM code that
firmware calls by fixed address. This is the mask ROM of the chip — it is not
authored by this project.

Redistributed file:  src/RP2350Sharp/bootrom_rp2350.bin (32 KiB)

It is compiled into the published RP2350Sharp assembly as an <EmbeddedResource>,
and is therefore redistributed in binary form inside the RP2350Sharp NuGet
package and inside any application that ships that assembly.

3. sweet-b — Western Digital Corporation (BSD-3-Clause)
-------------------------------------------------------------------------------

Upstream: https://github.com/westerndigitalcorporation/sweet-b

sweet-b is an elliptic-curve cryptography library. It is compiled into the
RP2350 boot ROM redistributed by this project (section 2 above), where the boot
ROM uses it to verify secure-boot signatures (src/main/arm/arm8_sig.c of
pico-bootrom-rp2350). It is therefore redistributed in binary form as part of
src/RP2350Sharp/bootrom_rp2350.bin.
